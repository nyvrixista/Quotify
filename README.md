# Quotify

Quotify is a modern, minimalist quote discovery web app built with HTML, CSS, and JavaScript. <br> <br>
It allows users to generate inspiring quotes, browse categories, save favorites using Local Storage, and copy quotes with a single click—all within a clean, responsive interface. <br> <br>
Created as a personal project, Quotify helped me strengthen my frontend development skills while building a polished, real-world application from scratch.
