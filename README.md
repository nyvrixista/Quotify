# Quotify

Quotify is a quote discovery game where every quote feels like a collectible.

Instead of simply displaying random quotes, Quotify uses rarity, discovery, collections, and achievements to make finding new quotes exciting.

---

## Features

### Quote Discovery
Generate random quotes and discover new entries.

### Rarity System
Quotes have different rarities:

- Common
- Uncommon
- Rare
- Epic
- Legendary
- Mythic

The rarer the quote, the more special the discovery.

### Collection
Every discovered quote is saved and added to your personal collection.

### Achievements
Unlock achievements by discovering quotes and finding rare ones.

---

## Why Quotify?

I wanted to combine the feeling of opening a game pack with something meaningful: quotes.

Every discovery should feel like finding something valuable.
