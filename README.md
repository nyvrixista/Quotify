Quotify

A modern and minimal quote discovery website designed to inspire users through meaningful words from influential people.

Quotify focuses on a clean, Apple-inspired design with smooth animations, beautiful typography, and a simple user experience.

Features:
Display inspiring quotes <br>
Generate random quotes
Copy quotes with one click
Modern minimalist UI
Responsive design
Fast and lightweight

Built With:
HTML5
CSS3
JavaScript
Google Fonts (Inter)
